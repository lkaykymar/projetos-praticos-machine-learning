# projetos-praticos-machine-learning
Repositório destinado aos meus estudos práticos de Machine Learning. Aqui reúno notebooks aplicando diferentes algoritmos de classificação, regressão e agrupamento, explorando desde o pré-processamento dos dados até a avaliação dos modelos utilizando conjuntos de dados reais.

**Observação: os relatórios completos de cada projeto, incluindo a fonte de cada base de dados, as análises realizadas e os resultados obtidos, estão disponíveis nos respectivos notebooks.**

## estudos

📘 naive_bayes_credit_risk.ipynb

Aplicação do algoritmo Gaussian Naive Bayes em um problema de classificação de risco de crédito. O estudo contempla análise exploratória dos dados, tratamento de valores inconsistentes, padronização das variáveis, treinamento do modelo e avaliação por meio de métricas como matriz de confusão e acurácia.

📘 decision_tree_census.ipynb

Aplicação do algoritmo Decision Tree Classifier em um problema de classificação de renda utilizando a base Adult (Census Income), disponibilizada pela UCI Machine Learning Repository. O estudo, desenvolvido como exercício acadêmico, contempla análise exploratória, visualização das distribuições das variáveis, codificação de variáveis categóricas com OneHotEncoder, treinamento do modelo e avaliação por meio de métricas como acurácia, precisão, recall e F1-score.
